# 异常检测与 AI 洞察 SOP（anomaly-sentinel）

前置：先加载 fundradar-persona（S1）。对 5 只持仓股 + 10 个关注板块每日盘后跑批；盘中用延时数据预检。一切统计计算调 calc 函数，本 skill 不写公式。

## 1. 六维定义与阈值（照抄《异常检测与AI洞察-模块设计 v0.1》§2）

| # | 维度 | 计算 | 触发阈值 |
|---|---|---|---|
| E1 | 资金流异常 | z = (今日主力净流入 − μ₂₀) / σ₂₀（20 日滚动） | \|z\| ≥ 2 普通异常；≥ 3 强异常 |
| E2 | 换手率异常 | 今日换手 vs 20 日分位数 | > P90 且 > 1.5×中位数 |
| E3 | 量能异常 | 今日成交额 z-score | \|z\| ≥ 2.5 |
| E4 | 板块资金突变 | 板块当日净流入 vs 5 日均值 | ≥ 3 倍（抢筹）或 ≤ −3 倍（撤退） |
| E5 | 炸板率异常 | 全市场炸板率 | > 30%，或较 5 日均值 ×2 |
| E6 | 梯队突变 | 最高连板数 | 较昨日 ±2 板（情绪骤变） |

判定口径：E1/E2/E3 按"个股"输出；E4 按"板块"输出；E5/E6 按"大盘"输出。

## 2. 计算（一律调 calc）

- E1：调用 calc 函数 zscore20（series=最近 21 个交易日该股主力净流入，含当日，单位亿元），取返回的 z。
- E3：调用 calc 函数 zscore20（series=最近 21 个交易日该股成交额序列），取返回的 z。
- E2：今日换手在 20 日中的分位数（取数层统计）；">1.5×中位数"为取数层前置过滤，命中时把实测分位传给 anomaly_judge。
- E4：板块当日净流入与 5 日均值之比，调用 calc 函数 ratio（numerator=当日净流入，denominator=5 日均值，label=板块资金倍数，unit_in=亿元）；5 日均值由盘后批统计给出。
- E5：取 em_limit_up_sentiment 现成炸板率统计值；与 5 日均值比较调 calc 函数 ratio。
- E6：最高连板数较昨日差（盘后批两日最高连板计数之差），仅作 anomaly_judge 入参。
- 综合判定：调用 calc 函数 anomaly_judge（fund_z=E1 的 z，turnover_pctile=E2 分位，vol_z=E3 的 z，board_ratio=E4 比值，zhapu_rate=E5 炸板率（%），ladder_delta=E6 差值）；level 取返回的 details.level，triggers 逐条读出。

基线规则：个股资金流基线不足 20 个交易日 → 不检测（zscore20 会返回 not_meaningful，按此提示"数据积累中"），不拿不足样本硬算。

## 3. 洞察模板（照抄《异常检测与AI洞察-模块设计 v0.1》§3.2）

> "〔个股〕今天主力资金净流入 X 亿，是过去 20 天平均水平的 X 倍，属于【资金异常流入】。它所在的〔板块〕今天 X 家涨停、资金净流入 X 亿（关联信息：〔今日上榜龙虎榜 / 有公告《XXX》〕）。资金异动本身不代表涨跌方向，请结合盘面判断。出处：资金流向数据（20 日统计）。"

铁律追加（写入系统提示词）：

- 洞察禁止出现"要涨/要跌/赶紧买/赶紧卖"类判断
- 禁止解释性猜测（"主力在出货"），只允许"与 XX 数据同时出现"的事实关联
- 每个洞察 ≤ 60 秒朗读

洞察要求：2-3 句大白话，禁方向判断；关联上下文（该股所属板块今日热度 / 龙虎榜是否上榜 / 最新公告）由取数结果自动拼装，不凭空编。

## 4. 推送分级（照抄《异常检测与AI洞察-模块设计 v0.1》§3.3）

| 级别 | 触发 | 行为 |
|---|---|---|
| 强异常（z≥3 / 板块×3） | 弹窗 + 语音朗读洞察 |
| 普通异常（z≥2） | 弹窗 + 洞察卡片（不自动朗读） |
| 每日洞察上限 | ≤ 3 条（超出只进"今日洞察"列表） |
| 免打扰 | 12:30-13:30 静默（默认） |

推送行为以 calc anomaly_judge 返回的 level 为准：strong → 语音朗读洞察；normal → 弹窗不朗读；每日 ≤3 条；免打扰 12:30-13:30 静默。

## 5. 洞察出口

1. 首页右侧："今日异常洞察"区（最多 2 条大字卡片）
2. 盘后复盘/晨报：完整版晨报新增可选段"昨天资金异动"（精简版不进，控制时长）
3. 问答：老人问"今天有什么异常吗？"→ 读今日洞察清单（qa-intents 意图 #24）

## 6. 规则

- 数字一律来自取数证据与 calc 输出；洞察只陈述事实关联，不做方向判断。
- 检测失败或基线不足：如实提示，不编值、不填充。
