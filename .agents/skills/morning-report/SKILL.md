# 晨报模板（morning-report）

前置：先加载 fundradar-persona（S1）满足人设与铁律；生成时间 = 交易日 08:30，数据 = 昨日盘后批 + 当日盘前公告；数字计算一律调 calc 函数，本 skill 不写公式。

## 1. 精简版六段（默认，约 1 分钟，逐句定义）

| # | 段落 | 话术 | 数据来源 / 降级 |
|---|---|---|---|
| ① | 开场 | "早上好，今天是 X 月 X 日，星期 X。" | 系统日期 |
| ② | 大盘一句 | "昨天大盘情绪（偏暖/平稳/偏冷），涨停 X 家，最高 X 连板。" | 涨停池；缺失→"昨天市场数据还没出全，稍后可在首页看" |
| ③ | 主线一句 | "资金最集中的方向是〔板块A〕，X 家涨停、净流入 X 亿，龙头是〔个股〕。" | 主线榜 Top1；若主线非科技链补一句"热点不在科技方向" |
| ④ | 持仓合并一句 | "您的 5 只持仓，X 涨 X 跌，最强的是〔个股〕涨 X%。今天主线（覆盖/偏离）您的持仓方向。" | 持仓行情+吻合度 |
| ⑤ | 风险一句 | 有风险："今天炸板偏多，追高要留神。"／无风险："今天没有特别需要提示的风险信号。" | 炸板率等；炸板率>30%触发 |
| ⑥ | 收尾 | "以上是公开数据解读，不构成投资建议。想听每只股票详细情况，点屏幕上的『完整晨报』。" | 固定 |

六段话术为固定文案，逐字使用；数字占位符（X）由数据或 calc 输出填入，不自行改写句式。

## 2. 全球要闻（精简版插入 2-3 条）

- 取数：rss_news / em_global_news / cls_telegraph，取 2-3 条。
- 每条一句大白话摘要，带出处；数字照抄取数结果，不心算不换算。

## 3. 完整版八段（晨报页"完整晨报"按钮切换，约 3-5 分钟）

**① 开场问候**（固定）

> "早上好，今天是 X 月 X 日，星期 X。"

**② 大盘情绪**（数据：涨停池统计）

> "昨天大盘情绪（偏暖/平稳/偏冷），涨停 X 家，最高 X 连板，炸板 X 家。"

- 情绪档：涨停 ≥60 偏暖；30-59 平稳；<30 偏冷

**③ 主线方向**（数据：主线板块榜热度分 Top 3）

> "资金最集中的方向是〔板块A〕，X 家涨停、净流入 X 亿，龙头是〔个股〕；其次是〔板块B〕……"

- 主线为科技链加一句"热点还在科技方向。"／主线跑偏："今天热点不在科技链，跑到了〔板块〕。"
- 热度分调 calc 函数 heat_score，不手算。

**④ 持仓体检**（数据：持仓行情+资金流+板块覆盖）

> "您持有的 5 只股票：〔个股1〕涨 X%、主力（净流入/净流出）X 亿；〔个股2〕……今天主线（覆盖/偏离）您的持仓，覆盖了〔板块+个股〕，〔个股〕不在今天的热点方向上。"

- ≥4 只同向时加提示："您的持仓都集中在科技链，今天（一起涨/一起跌），请注意这个特点。"

**⑤ 龙虎榜与游资**（数据：龙虎榜+席位标签）

- P0 降级话术（R3）："昨天共 X 只股票上龙虎榜，净买入最多的是〔个股〕X 亿。知名席位分析将在后续版本提供。"
- P0.5 完整版："昨天龙虎榜上，知名游资〔X〕买入了〔个股〕X 亿；机构买了〔个股〕……"
- 无知名游资动作 → "昨天龙虎榜没有知名游资的大动作。"

**⑥ 风险提示**（固定+动态）

- 动态项：炸板率偏高（>30%）→"炸板 X 家、比例偏高，说明追高资金有松动，短线要留神。"；连板高度骤降 →"连板高度从 X 板降到 X 板，接力情绪转弱。"
- 无显著风险 → "今天没有特别需要提示的风险信号。"

**⑦ 今日关注**（数据：次日主线关注清单，P0.5 起）

> "今天可以留意：〔板块1〕，连续 3 日资金净流入；〔板块2〕，昨天 4 家涨停……"

**⑧ 收尾**（固定）

> "以上是根据公开数据的解读，不构成投资建议。祝您今天看盘顺利。"

## 4. 降级话术

每段数据缺失时的固定替代句已列在 §1 表"数据来源 / 降级"列，逐字使用；龙虎榜段 P0 固定用 §3⑤ 的 R3 降级话术。缺失项逐段标"无数据"，不填充。

## 5. 交易日历规则

- 非交易日不生成晨报；屏幕提示"今天休市，无晨报"，节假日附恢复交易日。
- 是否交易日由 fetch_trade_calendar 判定，不凭记忆猜。
