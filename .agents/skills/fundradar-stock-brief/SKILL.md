# 个股速览报告（fundradar-stock-brief）

前置：先满足 fundradar-persona（S1）的铁律与大白话风格，再按本 skill 的四点 SOP 取数作答。用户画像 60 岁、跟资金动向；结论前置、短句、数字带出处，语音 ≤90 秒。

## 1. 四点 SOP（顺序固定：趋势 > 风险 > 前景 > 季报，附估值）

每点「先取数、后下结论」；数字只来自本轮取数工具返回或 calc 计算，禁止凭记忆编造；取不到写「未获取」。

### ① 趋势判断（技术面）
- 取数：`fetch_kline`（K 线 + 均线，近 60 日）；`em_fund_flow_120d`（备源 `sina_fund_flow`）看主力近 20 日净流入/流出。
- 计算：近 5/20/60 日区间涨跌幅，一律调 `calc range_return(closes, n)`（closes 为按时间升序的收盘价序列，n=5/20/60），禁止心算。
- 输出：近 20/60 日走势（上涨/下跌/横盘）；MA5/10/20 排列（多头/空头/纠缠）；近 5/20/60 日涨跌%；主力近 20 日净流入/流出金额。

### ② 风险与不利（反方视角）
- 取数：`em_stock_news`、财报端点、概念板块端点。
- 输出：行业风险 / 公司风险 / 估值风险 / 技术面风险各一句；反方观点（「为什么不买它」）；ETF 特别项——折溢价率（场内价 vs 净值，QDII 重点）；财报质量红旗（能取到才写，取不到写「未获取」）。

### ③ 前景分析（行业与催化）
- 取数：`em_stock_news`、`em_concept_blocks`、行业端点。
- 输出：公司业务一句话；所属行业/板块景气度；近期催化剂（新闻 / 产业事件 / 订单 / 政策）。

### ④ 季报与预期
- 取数：`fetch_financials`、`sina_income_statement`、`fetch_estimates`。
- 输出：最新财报要点（营收 / 净利 / 增速，带报告期）；一致预期（EPS、前瞻增速、机构家数）；财报质量核查（应计 / Beneish 等，取不到写「未获取」）。

### 附·估值（速览也要完整，用户拍板）
- 取数：`bs_valuation_history`（PE/PB 历史分位）、`fetch_pe_history`。
- 输出：估值贵/便宜（PE/PB 分位 + 一句话结论）；能取到的估值方法多法交叉，取不到写「未获取」，不编。

### ⑤ 所属板块要闻（板块利好 / 利空新闻）
- 取数：`em_concept_blocks`（个股概念板块归属）+ 板块新闻（RSS 新闻雷达按行业映射到四板块：科技链 / 新能源 / 医药 / 金融）。
- 映射：把个股概念板块名映射到四板块——AI/半导体/芯片/机器人/算力/服务器/消费电子→科技链；新能源/汽车/锂电/光伏/储能→新能源；医药/生物/医疗/创新药→医药；银行/证券/保险/券商→金融。
- 输出：该股所属板块前 2-3 条利好 / 利空新闻（标题 + 情绪标签），按影响力分降序；金融板块无对应 RSS 标签，用宏观口径近似并标「数据源受限·宏观口径」；取不到写「未获取」。

## 2. 三层触发规则

| 层 | 触发 | 内容 |
|---|---|---|
| 摘要层（默认） | 问「XX 什么情况 / 分析下 XX」 | 四点各 1-2 句 + 结论前置，末尾提示「点『看完整报告』看完整四点与估值出处」 |
| 完整层（展开） | 用户点「看完整报告」或说「看完整」 | 四点完整展开 + 估值 + 财报质量 + 数据出处与时间戳 |
| 深研层（可选） | 明确说「深度研究 XX」 | 转底座六阶段（company-research / equity-research 九章），分钟级 |

- 默认只给摘要层，不要主动长篇展开；只有用户明确「看完整」才给完整层；只有明确「深度研究」才进深研层。
- 摘要层末尾固定提示语（供前端「看完整报告」按钮感知）：「想看得更细，点『看完整报告』，我给您四点完整结论与估值出处。」

## 4. 纪律（继承底座宪法 + persona 铁律）

1. 数字必须来自工具返回，禁止凭记忆编造；取不到写「未获取」。
2. 每点结论带数据出处与时间戳。
3. 不荐股、不给买卖指令；趋势/前景只说事实与框架。
4. 大白话、结论前置、语音 ≤90 秒（摘要层）。
5. 冲突数据对账，不静默取舍。

## 5. 摘要层输出模板（四点各 1-2 句，结论前置，趋势在前）

> 结论一句话：〔个股〕近 20 日〔涨/跌〕X%，〔多头/空头/纠缠〕排列，主力近 20 日净〔流入/流出〕X 亿。出处：〔端点 · 日期〕。
>
> ① 趋势：近 5/20/60 日涨跌 X%/X%/X%（calc range_return）；MA5/10/20〔多头/空头/纠缠〕；主力近 20 日净〔流入/流出〕X 亿。出处：fetch_kline、em_fund_flow_120d。
>
> ② 风险：〔行业/公司/估值/技术面风险各一句〕；反方一句「为什么不买它」；〔ETF 折溢价 X%，若为 ETF〕；财报红旗〔有 / 未获取〕。出处：em_stock_news、财报端点。
>
> ③ 前景：公司业务一句话〔……〕；所属〔板块〕景气度〔……〕；近期催化剂〔新闻 / 订单 / 政策〕。出处：em_stock_news、em_concept_blocks。
>
> ④ 季报：最新〔报告期〕营收 X、净利 X、同比〔+/−〕X%；一致预期 EPS X、前瞻增速 X%（机构 X 家）；财报质量核查〔…… / 未获取〕。出处：fetch_financials、fetch_estimates。
>
> 附·估值：PE X（分位 X%）、PB X（分位 X%），〔贵 / 便宜 / 中性〕一句话。出处：bs_valuation_history、fetch_pe_history。
>
> ⑤ 所属板块要闻：〔板块名〕近期〔利好 / 利空〕：〔标题〕；〔利好 / 利空〕：〔标题〕（前 2-3 条，影响力降序）。出处：RSS 新闻雷达。
>
