# 主线雷达 SOP（mainline-radar）

前置：先加载 fundradar-persona（S1）满足人设与铁律；数字计算一律调 calc 函数，本 skill 不写公式。

## 1. 取数端点（CATALOG 登记 id）

| 端点 id | 拿什么 |
|---|---|
| em_zt_pool | 涨停池（个股/板块涨停家数、连板高度、最高板） |
| em_zb_pool | 炸板池（炸板家数） |
| em_board_fund_flow | 板块资金流（净流入，亿元，可负） |
| em_limit_up_sentiment | 三池计数（涨停/炸板/昨涨停情绪统计，含现成炸板率统计值） |
| ths_limit_up_pool | 涨停原因 |

## 2. 计算（一律调 calc，禁止手写公式）

- 热度分：调用 calc 函数 heat_score（zt_count=该板块涨停家数，flow_yi=该板块资金净流入（亿元），height=最高连板），保留 1 位小数由函数完成，直接引用返回的 value。
- 炸板率：优先取 em_limit_up_sentiment 的现成统计值；未提供时调用 calc 函数 ratio（numerator=em_zb_pool 炸板家数，denominator=em_zt_pool 涨停家数与 em_zb_pool 炸板家数之和，label=炸板率，unit_in=家）。分母仅为两家数之和，作 ratio 入参，不作其他运算。

## 3. 输出模板

主线 Top3，逐行输出：

| 项 | 内容 |
|---|---|
| 板块名 | 〔板块A〕〔板块B〕〔板块C〕 |
| 涨停家数 | 各板块涨停家数 |
| 最高板 | 各板块最高连板数 |
| 资金 | 各板块资金净流入（亿元） |
| 龙头 | 各板块龙头股 |

随后输出：

- 是否覆盖持仓：对照持仓清单（600183/300285/000938/000977/002475），说明覆盖了哪几只、哪只在热点方向上、哪只不在。
- 一句大白话结论（结论前置，带出处，末尾免责，遵守 S1）。

## 4. 数据缺失

逐项标"无数据"，不填充、不猜测、不用旧值冒充。
