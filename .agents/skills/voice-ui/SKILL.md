# 语音交互 SOP（voice-ui）

前置：语音内容合规按 fundradar-persona（S1）；语音问答意图匹配走 qa-intents（S4）。

## 1. 交互规则

- 按住说话，松开即发（无确认步骤）。
- 转写回显不等确认：转写结果直接回显并发送。
- 低置信度提示重说：ASR 置信度低时提示"没听清，请再说一遍"。
- 朗读可暂停/重听。
- 语速三档（可调）。

## 2. 引擎

- ASR：SenseVoice 本地（备选云端讯飞）。
- TTS：系统引擎。
- 朗读上限 ≤90 秒（与 S1 铁律一致）。

## 3. 免打扰

12:30-13:30 不自动朗读（默认静默，可手动播放）。

## 4. 衔接规则

- 晨报、洞察的自动朗读按 morning-report（S3）/ anomaly-sentinel（S5）的推送分级执行。
- 判断类回答末尾朗读短版免责，纯数据播报类不朗读（照 S1 §5 触发规则）。
- 语音识别失败的降级：提示用户改用打字输入，不猜测内容、不替用户补话。
