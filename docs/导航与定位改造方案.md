# 导航与定位改造方案

> 版本：v1.2.x 迭代 · 状态：待确认开工
> 背景：产品已从「60 岁专属」转向「大众产品」。现有导航（侧栏双区 + 顶栏面包屑）在页面增多、
> 长页面滚动场景下，存在「找页面靠滚动、长页面内找不到位置」的问题。
> 参考后台菜单交互最佳实践（工作区切换 / 菜单搜索 / 面包屑下拉等）与滚动定位需求，整理如下。

---

## 一、改造项总览（6 项，按优先级）

| 优先级 | 改造项 | 解决的问题 | 预估成本 |
|---|---|---|---|
| P0 | 菜单搜索（Cmd+K / Ctrl+K） | 页面多，找页面靠上下翻 | 中（新组件） |
| P0 | 页内锚点 + 滚动高亮（scrollspy）+ 回顶部 | 长页面内找不到位置 | 中（通用 hook + 三个页面接入） |
| P0 | 面包屑下拉 | 页面间跳转要回侧栏 | 低（改顶栏） |
| P0 | 滚动进度条（全局） | 「我在哪」的直接反馈 | 低（小 hook + 样式） |
| P1 | 工作区切换（常用 / 进阶） | 双区认知不清晰 | 中（改侧栏结构） |
| P2 | 悬停二级面板（桌面端增强）+ 拖动排序 | 效率提升 / 个性化 | 中-高，看反馈再定 |

---

## 二、各项详情

### 1. 菜单搜索（Cmd+K / Ctrl+K）· P0

- **交互**：桌面端快捷键 Cmd+K / Ctrl+K（顶栏加一个搜索入口按钮），弹出居中搜索框；
  输入关键词实时过滤全部导航项（含子栏目），回车或点击跳转。
- **数据源**：复用 `Layout.tsx` 的 `NAV_CORE` + `NAV_ADV` + `NAV_GROUPS`（单一数据源，不另维护一份菜单）。
- **匹配**：中文关键词包含匹配；预留拼音首字母匹配（大众产品常见，可后加）。
- **涉及文件**：
  - 新增 `desktop/src/verticals/finance/components/fundradar/FrCommandPalette.tsx`（弹层 + 列表）
  - 新增 `desktop/src/verticals/finance/hooks/useCommandPalette.ts`（快捷键 + 开关状态）
  - `Layout.tsx`：挂载组件 + 顶栏搜索按钮
- **验收**：快捷键唤起、过滤正确、回车跳转、Esc 关闭、焦点管理（打开聚焦输入框，关闭还焦）。

### 2. 页内锚点 + scrollspy + 回顶部 · P0

- **交互**：长页面的区块标题做成锚点导航（页面顶部横向 chip 条或侧边小目录），
  滚动时**当前区块自动高亮**（这就是「感知滚动位置」）；点击锚点平滑滚动到区块；滚到底出现「回顶部」悬浮按钮。
- **适用页面**（长页面才加，短页面不加）：
  - 每日复盘（晨报 / 主线 Top3 / 涨停梯队 / 炸板池 / 游资动向 / 持仓吻合度）
  - 个股报告（评分 / 四大指标 / 风险点 / 多空倾向）
  - 个股研究 / 我的研报（六阶段研报长文档）
- **实现**：`IntersectionObserver` 做高亮（不依赖滚动事件节流）；区块加 `id`；锚点 `scrollIntoView({behavior:"smooth"})`。
- **涉及文件**：
  - 新增 `desktop/src/verticals/finance/hooks/useScrollSpy.ts`（通用：传区块 id 列表，返回当前 id）
  - 新增 `desktop/src/verticals/finance/components/fundradar/FrSectionNav.tsx`（锚点 chip 条）
  - 新增 `desktop/src/verticals/finance/components/fundradar/FrBackToTop.tsx`（回顶部）
  - 三个长页面接入
- **验收**：滚动时高亮跟随、点击平滑定位、回顶部按钮出现/消失正确、触屏可用（大点击区）。

### 3. 面包屑下拉 · P0

- **交互**：顶栏「工作空间 / 当前页」的面包屑改为可点击：点击当前页名弹出同级页面列表
  （含常用区 + 进阶区全部一级页面），点击直达。面包屑仍是「位置感知」的一部分。
- **涉及文件**：`Layout.tsx` 顶栏段（小改动）
- **验收**：点击弹出、列表正确、跳转正常、Esc/点击外部关闭。

### 4. 滚动进度条（全局）· P0

- **交互**：顶栏下沿一条 2px 进度条，显示当前页滚动百分比（长文档最有用）。
- **实现**：`main` 容器 scroll 事件（rAF 节流）→ 宽度百分比。
- **涉及文件**：`Layout.tsx` + 小 hook（可并入 useScrollSpy 或独立 useScrollProgress）
- **验收**：进度随滚动更新、短页面（无滚动）不显示或满格、性能无感。

### 5. 工作区切换（常用 / 进阶）· P1

- **交互**：侧栏顶部的「常用区域」与「进阶研究区」改为明确的**切换器**（tab 式）：
  默认在常用区（8 页），切到进阶区显示 10 页。不再是一长条滚动。
- **保留**：当前「进阶区整区折叠」逻辑与新切换器二选一（切换器替代折叠，避免两套并存）。
- **涉及文件**：`Layout.tsx` 侧栏段
- **验收**：切换正确、当前工作区高亮、路由跳转不受影响、既有折叠偏好键平滑迁移或废弃。

### 6. 悬停二级面板 + 拖动排序 · P2（看反馈再定）

- **悬停二级面板**：桌面端 hover 展开子栏目（资讯雷达 / 产业信号 / 板块中心），触屏保持点击展开。
- **拖动排序**：允许用户拖动常用区菜单排序，偏好持久化到 localStorage。
  需引入拖拽方案（dnd-kit 或原生 HTML5 DnD），成本较高，放到反馈之后再评估。

---

## 三、实施顺序

1. **第一批（P0 四项）**：菜单搜索 → 页内锚点+scrollspy+回顶部 → 面包屑下拉 → 滚动进度条。
   这四项互相独立，可并行开发；合并后一起验收。
2. **第二批（P1）**：工作区切换（涉及侧栏结构，单独做，避免与 P0 冲突）。
3. **第三批（P2）**：视用户反馈再定。

---

## 四、质量与发布纪律

- 每项改动：前端类型检查通过（`pnpm --dir desktop run typecheck`）+ 全量测试通过（`node --test desktop/test/*.test.ts`）。
- 新增交互带测试：搜索过滤逻辑、scrollspy 状态映射等纯逻辑抽成函数并加用例。
- **本轮不打包、不发版**：代码照常提交推送到 main；**积累多点更新后再统一打包**
  （Mac dmg + Windows 安装包一起出）。
- 视觉遵循现有 DSH 蓝主题与组件风格（`fr-*` 前缀、大点击区、深浅色适配）。
