# To Be Future 资金雷达工作台 · 下载说明

## 这是什么

To Be Future 资金雷达工作台是一款面向 A 股的"跟资金动向型"个人投研工作台。打开就能看：评分榜、板块利好利空新闻、世界股票指数、龙虎榜（游资席位标签）、每日复盘（晨报 / 复盘结论 / 次日关注）、自己的持仓，以及带评分的个股报告。还有一个能对话的 Agent，支持 Plan / Goal 模式和多模型切换。界面为大字蓝主题、红涨绿跌，可调四档字号与深浅色，适合不盯盘的家人日常使用。

## 安装步骤

### Windows

1. 下载 `fund-radar-desktop-setup-1.2.0.exe`
2. 双击运行，按向导安装（可自选安装目录，例如 D 盘，免管理员权限）
3. 安装完成后，桌面与开始菜单会生成"To Be Future 资金雷达"快捷方式
4. 双击快捷方式即可打开，无需每次解压

> 首次双击若 Windows SmartScreen 提示"未知发布者"，属未签名安装包的已知提示，请自行确认来源后选择"仍要运行"。

### Mac（Apple Silicon）

1. 下载 `fund-radar-desktop-1.2.0.dmg`
2. 双击打开 dmg，把「To Be Future 资金雷达」拖进「应用程序」文件夹
3. **首次打开**：双击 App 会提示「无法打开，因为无法验证开发者」——
   右键 App →「打开」→ 再点「打开」即可（只需一次，之后正常双击）

> 未签名属已知状态；**不要**关闭「系统设置 → 隐私与安全性」的整体防护。

## 首次使用（接入 DeepSeek Key）

1. 打开软件后进入"设置"→ AI 接入
2. 选择 DeepSeek，填写 API Key
3. 点击"测试并保存"，成功即可使用对话、晨报、复盘结论等 AI 功能

Key 只保存在本机浏览器，不进入仓库、日志或后端配置；共享电脑用完请主动清除。

## 更新方式

应用启动后自动检查更新（GitHub Releases），发现新版本会在右下角提示下载。
当前版本 v1.2.0。

## 卸载方法

- **Windows**：打开"设置 → 应用 → 已安装的应用"，找到"To Be Future 资金雷达"，点击卸载；或在安装目录下运行卸载程序。
- **Mac**：把「应用程序」里的「To Be Future 资金雷达」拖进废纸篓。

卸载不删除你本机保存的持仓与报告数据，如需彻底清除请手动删除对应数据目录。
