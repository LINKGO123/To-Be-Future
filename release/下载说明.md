# To Be Future 资金雷达工作台 · 下载说明

## 这是什么

To Be Future 资金雷达工作台是一款面向 A 股的"跟资金动向型"个人投研工作台。打开就能看：评分榜、板块利好利空新闻、世界股票指数、龙虎榜（游资席位标签）、每日复盘（晨报 / 复盘结论 / 次日关注）、自己的持仓，以及带评分的个股报告。还有一个能对话的 Agent，支持 Plan / Goal 模式和多模型切换。界面为大字蓝主题、红涨绿跌，可调四档字号与深浅色，适合不盯盘的家人日常使用。

## 安装步骤

### Windows

1. 下载 `To Be Future 资金雷达-1.2.0-Setup.exe`
2. 双击运行，按向导安装（可自选安装目录，例如 D 盘，免管理员权限）
3. 安装完成后，桌面与开始菜单会生成"To Be Future 资金雷达"快捷方式
4. 双击快捷方式即可打开，无需每次解压

> 首次双击若 Windows SmartScreen 提示"未知发布者"，属未签名安装包的已知提示，请自行确认来源后选择"仍要运行"。

### Mac

macOS（arm64）安装包待发布。

## 首次使用（接入 DeepSeek Key）

1. 打开软件后进入"设置"→ AI 接入
2. 选择 DeepSeek，填写 API Key
3. 点击"测试并保存"，成功即可使用对话、晨报、复盘结论等 AI 功能

Key 只保存在本机浏览器，不进入仓库、日志或后端配置；共享电脑用完请主动清除。

## 更新方式

自动更新待配置。当前版本 v1.2.0，请关注发布渠道获取新版安装包。

## 卸载方法

Windows：打开"设置 → 应用 → 已安装的应用"，找到"To Be Future 资金雷达"，点击卸载；或在安装目录下运行卸载程序。卸载不删除你本机保存的持仓与报告数据，如需彻底清除请手动删除对应数据目录。
