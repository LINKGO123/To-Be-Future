## 3. 安装步骤

### 3.1 双击安装包

双击下载好的 `fund-radar-desktop-setup-1.2.0.exe`。

### 3.2 SmartScreen 提示（未签名，属正常）

安装包未做代码签名，Windows SmartScreen 会提示「Windows 已保护你的电脑」：

1. 点「**更多信息**」
2. 再点「**仍要运行**」

已确认来源、确认是官方安装包后再放行；如不确定来源，请先核对发布页提供的 SHA256 校验值。

### 3.3 安装向导

1. 语言默认简体中文，点「**下一步**」
2. 选安装目录：默认在用户目录下，可点「浏览」改到 D 盘等任意有写权限的位置（免管理员权限）
3. 快捷方式：默认在桌面与开始菜单创建「To Be Future 资金雷达」快捷方式，保持勾选即可
4. 点「**安装**」，等待进度条走完
5. 点「**完成**」——完成后会自动启动软件

### 3.4 打开软件

之后双击桌面上的「To Be Future 资金雷达」快捷方式即可打开，无需每次解压。

## 4. 首次使用（接入 DeepSeek Key）

对话、晨报、复盘结论等 AI 功能需要先接入自己的模型 Key：

1. 打开软件，进入「**设置**」→「**AI 接入**」
2. 选择 **DeepSeek**，填写 API Key（以及服务地址与模型名）
3. 点「**测试并保存**」，测试成功后才生效

说明：

- Key 只保存在本机浏览器 localStorage，仅在调用时经本机后端转发给所选模型服务商，不进入仓库、日志或后端配置
- 共享电脑用完请主动清除

---

## 5. 卸载

Windows 卸载方式（二选一）：

1. 打开「设置 → 应用 → 已安装的应用」，找到「To Be Future 资金雷达」，点「卸载」
2. 或在安装目录下运行卸载程序

卸载不会删除你本机保存的持仓与报告数据；如需彻底清除，请手动删除对应数据目录。

---

## 常见问题

- **打开提示「未知发布者」**：见第 3.2 节，未签名属正常，确认来源后放行即可。
- **AI 不回复**：确认已在「设置 → AI 接入」完成 DeepSeek Key 的测试并保存。
- **数据为空 / 显示示例数据**：行情数据来自公开渠道，可能有延迟或缺失；盘中数据会自动刷新，盘后数据当天不变。
